Flagged for review (see Phase 0 report): this is the one chart that doesn't map cleanly onto a stock Chart.js type. Modeled as a horizontal 100%-stacked bar with 2 categories (Assets / Liabilities & Equity); each stack's segments are a different "dataset slot" per position so per-segment names/colors/tooltips can differ between the two bars (a real per-category dataset, not shared labels). The current/non-current divider (the black rule in the current SVG) needed a small custom Chart.js plugin (afterDatasetsDraw) -- there's no built-in for it. The year selector swaps chart.data.datasets and calls chart.update() client-side, reusing the same all-years-embedded-in-one-payload approach the current bsShowYear() hide/show already uses (confirmed in company_detail.html: all years are already rendered server-side and toggled via a hidden .bs-year div per year, not a server re-render -- so this is a drop-in replacement for that mechanism, not a new one).
